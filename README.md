# Bayesian Deep Learning-Based Fidelity Estimation for UAV Communication Digital Twins

## Project Overview
This project estimates the fidelity of UAV communication digital twins using Bayesian deep learning techniques.

## Project Contents
- ML_PROJECT.ipynb: Model implementation and experiments
- app.py: Dashboard application
- Dataset/: Dataset files
- DATASET_README.md: Dataset documentation
- UAV_EDA_Report.pdf: Exploratory Data Analysis report
- Literature_Survey-01.pdf: Literature survey paper 1
- Literature_Survey-02.pdf: Literature survey paper 2
- UAV_Digital_Twin_1STPPT.pptx: First project presentation
- UAV_Digital_Twin_2ND_PPT.pptx: Second project presentation
- UAV_Digital_Twin_Project_Report.docx: Final project report

## Technologies Used
- Python
- Jupyter Notebook
- Bayesian Deep Learning
- Data Analysis and Visualization

## Objective
To estimate digital twin fidelity using UAV communication metrics such as throughput, latency, packet loss, RSSI, SNR, and SINR.
